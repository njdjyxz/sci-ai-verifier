# Synthetic chemical mass subject

This skill calculates the neutral molecular mass of flat CHNOPS formulas using H-1, C-12, N-14, O-16, P-31 and S-32.

The output is a plain decimal in Da. Charges, groups, hydrates, isotope labels and other elements are outside its scope.

This is an integration-test submission. The replay adapter returns predetermined answers without running these instructions. A fixture pass demonstrates the verifier workflow only.
